# Synthetic knowledge collection: "Nimbus Workspace"

No knowledge collection was supplied, so a small corpus was written for a **fictional**
SaaS product. It contains no real company data. The two PDFs are generated by
`python -m eval.build_corpus` into `eval/corpus/` (font-size headings, several pages, repeated header and footer);
the other files are hand-written.

| File | Format | Kind | Version / date | Planted test content |
|---|---|---|---|---|
| admin_guide_v3.pdf | PDF (4 pages) | manual | v3.0, 2025-02-15 | roles, SAML SSO setup, password reset (24 h link, 5 attempts / 15 min lock), API keys (10 per workspace, rotate 90 days) |
| billing_policy_v2.pdf | PDF (2 pages) | policy | v2.0, 2025-03-01 | **annual refunds within 30 days**, Pro $12/$10, 7-day grace period |
| billing_faq.md | Markdown | faq | 2023-06-10 | **refund within 14 days** → value conflict with the policy |
| api_reference_v2.html | HTML | manual | v2.4, 2023-09-12 | **100 requests/min**, basic auth supported, error table |
| release_notes_3_0.md | Markdown | release notes | v3.0, 2025-04-20 | **300 requests/min**, basic auth deprecated → version conflict |
| security_faq.md | Markdown | faq | 2025-02-01 | MFA, encryption, **deleted data kept 90 days** |
| data_retention_policy.txt | TXT | policy | v1.2, 2025-05-01 | **Enterprise 180 days**, Free/Pro 90 days → *scoped*, not a conflict |
| troubleshooting.txt | TXT | support article | 2025-03-15 | ERR-401 / ERR-403 / ERR-429 (exact-token retrieval), "cannot sign in" |
| usage_limits.html | HTML | policy | 2025-01-10 | users, storage and workspaces per plan → ambiguity ("what's the limit?") |
| onboarding_guide.txt | TXT | manual | — | uses "tenant" for workspace (terminology test), invitations expire in 7 days |

**Terminology variations:** SSO ↔ SAML ↔ identity provider, seats ↔ users, workspace ↔ tenant,
"can't sign in" ↔ authentication / password reset.

**Deliberate gaps (unanswerable):** parental leave, on-premise pricing, mobile offline mode,
DPA signing process. These topics are verified absent from every document.
