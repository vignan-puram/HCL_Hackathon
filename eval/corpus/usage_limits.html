Plan Usage Limits

Effective date: 2025-01-10

This policy describes the usage limits that apply to each Nimbus Workspace plan. Limits are enforced per workspace unless stated otherwise. Admins can see current usage in Admin Console > Usage.

Users per Plan

The Free plan includes up to 5 users. The Pro plan includes up to 50 users per workspace. The Enterprise plan has no fixed limit on users; the number of users is set in the customer's contract.

Guests do not count towards the user limit, but each workspace can have at most 20 guests on the Free and Pro plans.

Storage per Plan

PlanStorage per workspaceMaximum file size
Free2 GB100 MB
Pro100 GB250 MB
Enterprise1 TB250 MB

When a workspace reaches its storage limit, uploads are blocked until files are deleted or the workspace is upgraded. Files in the trash still count towards storage.

Workspaces per Account

A Free account can own 1 workspace. A Pro account can own up to 10 workspaces. Enterprise accounts can own an unlimited number of workspaces.

What Happens When You Exceed a Limit

Admins receive an email when usage reaches 80% of any limit. Existing data is never deleted because a limit was exceeded; only new uploads, new users or new workspaces are blocked.
